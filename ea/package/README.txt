MRTRADER
========
ربات ساده طلا و فارکس برای متاتریدر ۵ / آلپاری
سبک نینجا: ورود با Buy Stop و Sell Stop، بدون گرید و بدون مارتینگل.

هر دوست این پوشه را می‌گیرد و روی سیستم خودش نصب می‌کند.
محیط جداست. به فایل‌های بقیه کار ندارد.

چه کار می‌کند
- مشخصات حساب آلپاری را از متاتریدر می‌خواند (موجودی، اکوئیتی، مارجین، سود)
- طلا (XAUUSD) و EURUSD
- بالای سقف اخیر Buy Stop، زیر کف اخیر Sell Stop می‌گذارد
- حد ضرر و حد سود با ATR
- ریسک هر معامله ۰.۵٪ موجودی
- ۳۰ دقیقه قبل و بعد خبر مهم Forex Factory معامله نمی‌کند
- حداکثر یک پوزیشن در هر نماد

سود تضمینی نیست. اول روی دمو تست کنید.

نصب برای تو یا دوستانت
1. متاتریدر ۵ آلپاری را نصب کنید و با حساب دمو وارد شوید
2. install.bat را اجرا کنید
3. در متاتریدر F4 بزنید، MRTRADER را Compile کنید (F7)
4. Tools > Options > Expert Advisors:
   - Allow algorithmic trading
   - Allow WebRequest for:
     https://nfs.faireconomy.media
5. AutoTrading را روشن کنید
6. ربات را روی چارت طلا، تایم‌فریم H1 بکشید
   تیک Allow Algo Trading را بزنید

اگر نماد طلا GOLD بود نه XAUUSD، در تنظیمات ربات بنویسید:
GOLD,EURUSD

InpAllowTrading = false یعنی فقط پنل حساب را نشان بدهد.
